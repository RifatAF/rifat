# BodyPassport: аудит концепции и кода

Дата: 5 октября 2026. Объект: архив `BodyPassport-full.zip` (36 файлов, около 420 КБ кода и данных; папки `models/`, `voice/` и `data/body3d.bin` в архив не входили).

## 1. Концепция

**Что это.** Веб-приложение (PWA) без сборки: телефон стоит на полу, человек 2–5 минут выполняет протокол движений, камера с MediaPipe Pose считает углы, правила переводят их в карту «перегрузка / укорочение / слабость» по 34 мышцам и дают итог из трех строк: «Укрепить / Растянуть / Расслабить» плюс одна измеренная деталь.

**Два продукта в одном коде.**

| Режим | Для кого | Где данные |
|---|---|---|
| Клиент | человек с болью или интересом к осанке | `localStorage` и IndexedDB в браузере |
| Кабинет специалиста | кинезиотерапевт, тренер, массажист, студия | IndexedDB на телефоне специалиста, отдельная база на аккаунт |

**Конвейер анализа** (`js/analysis.js`): кадры → сглаживание → поиск нижних точек приседа → признаки (`features`) → 27 правил `bodymap.json` → тонус мышц (`tones`, с реципрокным торможением по Янде как гипотезой) → 15 цепей компенсации (`chains`) → выведенные звенья (`applyInferred`). Пограничные значения ослабляются и помечаются «на границе нормы».

**Передача клиент → специалист.** Специалист отправляет ссылку `#inv=` (на конкретного клиента) или `#join=` (одна на всех новых). В ссылке ключ AES-GCM 256; клиент шифрует результат у себя, сервер `api/relay.js` хранит только конверт, специалист забирает и расшифровывает.

**Сервер** (Vercel): `api/auth.js` вход через Google и Telegram, сессия в подписанной HMAC cookie, профили в приватном Vercel Blob; `api/relay.js` ретранслятор шифрованных результатов.

**Монетизация.** Старт бесплатно (до 5 клиентов), Про 15 $/мес, Студия 39 $/мес. До 31.12.2026 Про бесплатно всем специалистам. Ограничения тарифа проверяются только в браузере.

### Сильные стороны
1. Видео не покидает телефон, сервер видит только шифротекст: сильный аргумент приватности.
2. Честность методики: пометки «слабый признак», «на границе нормы», «предположение по цепи», проверка руками в гипотезе, сравнение с погрешностью съемки в «было → стало» и «повторяемости».
3. Три слоя результата у специалиста (Измерено / Гипотеза / Назначение) отделяют замер от интерпретации.
4. Скрининг противопоказаний перед тестом и облегченные варианты после «Не могу».

### Расхождения концепции и реализации
| Обещано | Факт |
|---|---|
| `/pricing`, тариф Студия: «общая база клиентов», «отчет с логотипом студии» | Не реализовано: база только на одном телефоне, логотипа в отчете нет |
| Ограничения тарифа | Только в браузере (`plans.js`), обходятся правкой `localStorage`/консолью. Пока Про бесплатен, это не мешает, но до конца беты нужна проверка на сервере |
| Клиентские ссылки `#join=` «одну ссылку можно отправлять разным людям» | Любой получатель ссылки может прислать произвольные данные в кабинет. До исправления это давало вставку HTML (см. S1) |
| «Поделиться ссылкой: данные зашифрованы в самой ссылке» | Ссылка `#r=` только сжата и закодирована base64, без шифрования (исправлен текст, S4) |
| Дата конца беты | Задана дважды: `BETA_PRO_UNTIL` на сервере и константа в `plans.js`. При продлении беты их легко рассинхронизировать |
| Данные кабинета «только на этом телефоне» | Потеря телефона = потеря базы; есть напоминание о резервной копии, но нет облака |

## 2. Найденные ошибки и исправления

Серьезность: **В** высокая, **С** средняя, **Н** низкая. Все пункты со статусом «исправлено» внесены в код этой ветки.

### Безопасность
| # | Сер. | Где | Проблема | Статус |
|---|---|---|---|---|
| S1 | В | `pro.js` `pullResults`, `result`, `compare`, `motionViewer` | Результат из дома принимался без проверки. Ключи `quality`, `limits`, `poses`, причины «не могу» выводились в HTML без экранирования. Любой, у кого есть ссылка `#join=`/`#inv=`, мог вставить HTML в кабинет специалиста. Воспроизведено: `<img onerror>` выполнился в оригинале. В проде скрипт в атрибуте блокирует CSP, но вставка разметки (ложные кнопки, ссылки) остается | Исправлено: `cleanRemote()` пропускает только ожидаемые поля и типы, все выводы экранированы |
| S2 | С | `app.js`, ссылка `#r=` | Чужая ссылка-результат шла в анализ как есть: битая структура роняла карту | Исправлено: `cleanResult()` оставляет только числа в известных полях |
| S3 | Н | `api/auth.js` | Telegram: без `auth_date` проверка срока давала NaN и пропускала данные (подпись все равно нужна). `Origin: null` ронял запрос с ошибкой 500 вместо 403. `setplan` с `days: 0` давал 30 дней | Исправлено |
| S4 | С | `app.js` `shareResult` | Текст обещал шифрование ссылки на карту, которого нет | Исправлено: текст говорит, что карту увидит любой со ссылкой |
| S5 | Н | `auth.js` `loginScreen` | Снятая галочка согласия не удаляла сохраненное согласие, и вход в Telegram Mini App шел автоматически | Исправлено |
| S6 | Н | `pro.js` `pullResults` | Нерасшифровываемые записи не удалялись и занимали лимит 20 записей на ссылку: мусор мог заблокировать ссылку | Исправлено: такие записи удаляются |
| S7 | Н | `api/relay.js` | Любой вошедший специалист может прочитать (шифротекст) и удалить записи по чужому id, если знает его. Id случайные 128 бит, поэтому риск низкий | Не меняли: нужна привязка ящика к владельцу на сервере |

### Не исправлено (нужно решение владельца)
1. Проверка тарифа на сервере и единая дата беты.
2. Обещания тарифа Студия: общая база и логотип.
3. Привязка ящиков relay к специалисту на сервере (S7).
4. Удаление аккаунта не удаляет неразобранные результаты в relay.
5. Лимит 200 ссылок за один запрос `pullResults`: у специалиста с большим числом приглашенных клиентов часть результатов не заберется.

## 3. Проверка
- `node --check` для всех JS: без ошибок. Хэши inline-скриптов в CSP совпадают с `index.html`.
- Анализ на демо-данных (Node): правила, тонус и цепи считаются, `trunk_back` получает полную силу.
- Chromium (Playwright), локальный сервер без камеры и модели:
  - клиент: знакомство, карта с тестом без стойки (раньше падала), один блок ограничений, вставка HTML в причинах не исполняется, ссылка `#r=` с мусором открывается без ошибок;
  - кабинет: результат из дома с HTML во всех полях. Оригинал: скрипт выполнился, вкладка «Назначение» упала. Исправленная версия: имя показано текстом, скрипт не выполнился, вкладки открываются, нерасшифровываемая запись удалена.
- Не проверено: съемка с камерой и голос (в архиве нет `models/` и `voice/`), вход Google и Telegram (нужны ключи), работа API на Vercel.
