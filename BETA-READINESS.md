# BodyPassport: готовность к закрытой бете

Дата: 12 октября 2026. Версия кэша: bp-v83. Состояние: ветка main после PR #52.

## Вердикт

Закрытую бету можно начинать: 5–10 специалистов и до 30 клиентов по ссылкам, с явной пометкой «бета, оценка движения, не диагноз». Для открытого запуска пока рано, причины в разделе «Что мешает открытому запуску».

## Что готово

| Область | Состояние |

| Тест перед камерой | Голосовые подсказки мужским голосом, счет повторов с первого слова команды, кнопка «Не могу», сглаживание скелета (One Euro), оценка качества съемки |
| Анализ | 32 правила по признакам, веса по литературе, проверка отрыва пятки по реальному подъему, прямой тест икры важнее косвенных признаков |
| Специалист | Кабинет, все клиенты, тест рядом и по ссылке с выбором протокола, разбор с гипотезами и проверкой руками, назначение, отчет клиенту, ретест, календарь |
| Клиент | Тест по ссылке с зонами боли и комментарием, карта тела 2D и 3D (один набор зон), упражнения с анимацией, голосом и стороной, свой кабинет |

## Как запускать бету

1. На Vercel задать `ADMIN_IDS` со своим Telegram id (`t_<id>`), чтобы приходили сообщения о жалобах и калибровках.
2. Telegram-бот для клиентов: задать `TG_WEBHOOK_SECRET` (любая длинная строка) и `TELEGRAM_BOT_USERNAME`, затем один раз открыть `https://api.telegram.org/bot<токен>/setWebhook?url=https://<домен>/api/remind?a=tg&secret_token=<TG_WEBHOOK_SECRET>`. Без этого кнопка клиента пишет «Бот пока не подключен».
3. Пройти тест самому на двух телефонах (Android и iPhone), сохранить видео теста, проверить счет повторов и голос.
4. В «Администрирование» выключить учет своих действий («Не учитывать мои действия»).
5. Каналы ссылок уже размечены: калибровка `?src=calib`, тест по ссылке `?src=join`, ссылка из карточки `?src=inv`, приглашение специалиста `?src=pro`, ссылка на приложение `?src=app`.
6. Первая неделя: 3–5 знакомых специалистов, каждый делает 2–3 калибровки. Вторая неделя: клиенты по ссылкам.
7. Раз в 2–3 дня смотреть: Статистика (каналы, «где тупят», анкеты после теста), Калибровки → Сводка, Нормы по базе.
8. Веса применять от 3–5 разных специалистов на одну связь, пороги от 30 тестов с хорошей съемкой.

## Что смотреть в первые недели (метрики)

- Доля дошедших от «открыли ссылку» до «прошли тест» по каждому каналу: цель выше 50%.
- Средняя оценка в анкете после теста: цель 4 из 5; топ причин «что мешало».
- Экраны с медианой больше 60 с или нажатиями мимо кнопок больше 1 за показ.
- Калибровка: «находит из того, что тест может увидеть» и «гипотез подтвердил специалист»: сейчас 14% и 25% на 2 случаях одного человека, цель после 20 случаев выше 50%.
- Ошибки в браузере и сообщения «Отзыв» с типом «Ошибка».

## Риски и известные ограничения

1. **Точность не подтверждена на людях.** Пороги правил выбраны по литературе и автором; калибровка пока на 2 случаях одного человека. Отсюда формулировки «похоже», «гипотеза» и проверка руками.
2. **Хранение данных.** Сервер на Vercel (вне РФ). Для данных о здоровье граждан РФ по 152-ФЗ нужна локализация; перенос в российское облако запланирован (пункт P2) и ждет решения владельца. Для закрытой беты нужно явное согласие участников (оно есть в приложении).
3. **Голос.** Записи упражнений старые, на «ты»; у трех пар упражнений сторона называется только на экране. Новое упражнение «Подъемы на носок» без записи (читает голос телефона). Для перезаписи нужен исходный сервис голоса.
4. **3D-модель.** Исправление трапециевидной (группы были перепутаны) сделано по координатам сетки; на картинке не проверено, файла модели нет в репозитории.
5. **iPhone.** Сохранение видео теста на iPhone может открыть видео вместо загрузки (особенность Safari); на Android сохраняется в «Загрузки».
6. **Кабинет специалиста на телефоне.** Клиенты хранятся в браузере; есть резервная копия и предупреждения, но при очистке данных браузера без копии кабинет пропадет.
7. **Нормы по базе** начнут работать от 30 тестов; до этого действуют исходные пороги.

## Что мешает открытому запуску

- Локализация данных (152-ФЗ) и юридическая проверка формулировок.
- Подтверждение точности на 20+ калибровках от разных специалистов.
- Перезапись голоса упражнений в одном голосе с тестом.
- Проверка на 10+ моделях телефонов (особенно слабые Android и iPhone).

## Карта файлов

- `index.html`, `sw.js`, `manifest.webmanifest`: оболочка PWA, стили, офлайн-кэш.
- `js/app.js`: клиентская часть, тест перед камерой, карта, упражнения, админ-экраны (статистика, калибровки, нормы).
- `js/pro.js`: кабинет специалиста, карточки, разбор, отчеты, ссылки, калибровка.
- `js/analysis.js`: признаки по точкам позы, правила, тон мышц, цепочки, сверка калибровки.
- `js/calibreport.js`: сводка калибровки и обучение весов.
- `js/core.js`: камера, MediaPipe, сглаживание, голос, 3D, запись теста, загрузка базы знаний и выученных весов.
- `js/exfig.js`: анимированные фигуры упражнений (SVG).
- `js/track.js`, `js/grow.js`: статистика, каналы, экраны, отзывы, анкеты.
- `js/evidence.js`, `js/plans.js`, `js/auth.js`, `js/pdf.js`, `js/vas.js`: уверенность выводов, тарифы, вход, PDF, шкала боли.
- `data/*.json`: база знаний (правила, мышцы, цепочки, упражнения, 3D-разметка).
- `api/*.js`: сервер Vercel (вход, ретрансляция результатов, статистика, отзывы, калибровка и веса, нормы, отчеты, оплата, напоминания).
- `tests/*.mjs`: автотесты (`npm test`).
- `*.md`: исследования, аудиты, советы, ТЗ.
