## 5. Что говорит наука о точности камеры телефона

Для вальгуса колена по MediaPipe прямой валидации против 3D-мокапа с телефона нет. В [Heliyon 2024](https://doaj.org/article/2d283f6411874c82988f54dd2e60829f) MediaPipe завышал вальгус при приземлении на одну ногу по сравнению с Vicon, абсолютные значения не совпали, изменения коррелировали. В [исследовании на 254 спортсменах](https://link.springer.com/article/10.1007/s11548-024-03156-5) расхождение с Kinect во фронтальной плоскости небольшое, MediaPipe занижает. Сгибание колена с одной камеры: ошибка около 3–6° ([opinvisindi](https://opinvisindi.is/items/11277349-0a37-4fab-8b7c-6faa30b1e922)). Для PostureScreen есть [валидация в PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC5276769), это их главный аргумент перед врачами.

## 6. Повторяющиеся темы отзывов (10 из 10 категорий нашли подтверждение)

1. **Вылеты и зависания** (PostureScreen, Physitrack, MedBridge) бьют по оценке сильнее любой нехватки функций.
2. **Запутанная подписка и платные модули** (PostureScreen, OnForm, APECS, Kaia): люди злятся не на цену, а на сюрприз.
3. **Ошибки трекинга рушат доверие** (Hinge, Sword, Kaia, Kemtai, Kinovea): одна явная ошибка, и человек не верит остальному.
4. **Долго собирать программу** (MedBridge) против «за минуты» (Physitrack) решает выбор специалиста.
5. **Клиенты любят бумагу и PDF** (MedBridge).
6. **Заявления о точности без независимых данных** вызывают скепсис; валидация (PostureScreen) это аргумент продаж.
7. **Железо** (LiDAR у Kinetisense) отсекает частников.
8. **Место перед камерой** (Kemtai).
9. **Приватность видео** (Sword).
10. **Оценки в сторе и на Trustpilot расходятся** (Hinge 4,9 против 3,5): отзывы в сторе завышены.

## 7. Что это значит для BodyPassport

| Тема | Где мы сейчас | Что делать |
|---|---|---|
| Стабильность | PWA без установки, нет загрузки фото из галереи, значит нет главного бага PostureScreen | не добавлять тяжёлое без проверки на слабом Android; 3D только по запросу (уже так) |
| Цена | цены в долларах, бета бесплатна | одна понятная цена в рублях, без платных модулей и «пробника под видом покупки» |
| Доверие к трекингу | метки «замер / гипотеза», уверенность | опубликовать повторяемость и честно указать ошибку ±5° для 2D-угла; не показывать вальгус как точное число в градусах без оговорки |
| Программа | автоподбор из 43 упражнений | свои упражнения и сохранённые комплексы, сборка за минуту |
| Бумага | отчёт картинкой | PDF с логотипом специалиста |
| Железо | любой телефон | сохранить как главное преимущество против Kinetisense |
| Место | подсказки по постановке | указать минимум места на экране подготовки |
| Приватность | видео не уходит с устройства, E2E-релей | писать это крупно на экране согласия и в маркетинге |
| Видеоанализ тренеров | есть запись и скелет | не конкурировать с OnForm/Kinovea в беге; занять нишу «осмотр за 3 минуты с выводом по мышцам» |

Главная ниша: ни один найденный продукт не сочетает «любой телефон + без установки + вывод по конкретным мышцам с честной уверенностью + русский язык». Главный риск тот же, что у всех: одна видимая ошибка трекинга на приёме обнуляет доверие.
