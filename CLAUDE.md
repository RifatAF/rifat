# BodyPassport: заметки для работы

Ориентир на ближайшие 90 дней (с 19.10.2026): стратегия `docs/strategy/90_day_gtm.md`.
- B2B-first: продаём независимым специалистам по движению с повторными клиентами, рекомендации идут через их клиентов.
- Цепочка: понятная ценность → использование → повторное использование → оплата. Масштабируем только при оплатах и повторах, просмотры не в счёт.
- Задачи и прогресс: Trello «BodyPassport: 90 дней продвижения» (https://trello.com/b/Vcm8XDxn), карточки BP-01…BP-40. Юридические и клинические задачи на доске «BodyPassport: запуск и продажи» (https://trello.com/b/rYxEtKmk).
- Новые функции только под реальную проблему пользователя или дефект надёжности (BP-18). Рабочее не удалять и сильно не менять без согласования с Рифатом.

Границы обещаний (docs/legal_texts):
- клиенту показываем наблюдаемое и задачу тренировки («Укрепить», «Мягко укрепить», «Расслабить»), без состояний мышц, процентов, диагнозов и связи с болью;
- кабинет специалиста видит состояния (выбор по режиму сессии в `js/app.js`, `bySession`);
- с 22.10.2026 (ТЗ v4) серверная копия кабинета выключена флагом `CLOUD_BACKUP` и автокалибровка по умолчанию выключена: данные клиентов специалиста остаются на телефоне, копия только файлом. Фразу «фото не уходят с телефона» писать только после проверки сетевых запросов; результаты клиентов, прошедших тест по ссылке, по-прежнему идут через зашифрованный ящик.
- ТЗ v4 «Быстрый тест»: `docs/product/spec_v4.md`.
- С 23.10.2026 основа кабинета: быстрый тест по 4 фото. Тест по видео, тест из дома и сеанс спрятаны под «Полную версию» (`bp_full`, переключатель в «Администрировании», `fullMode()` в `js/pro.js`); старые результаты по видео открываются как раньше.

Дизайн с 24.10.2026: Apple Matte (`js/ds.js`, стили `html[data-ds=matte]` в конце `<style>` index.html, лендинг `js/landing.js`). Откат: галочка «Новый дизайн» в «Администрировании» или `DEFAULT = 'v3'` в `js/ds.js`; прежний лендинг `js/landing-v1.js`. Числа замеров моноширинным (JetBrains Mono, класс `mt-val`/`mono`).

Решения: хранилище пока Vercel Blob с копией в Cloudflare R2, перенос в РФ отложен (19.10.2026).

Сборка и проверка: `npm test`; сайт собирается `scripts/fetch-assets.mjs` в `public/` (папка `docs/` не публикуется); при изменении клиентского кода поднимать версию `V` в `sw.js`.
Не коммитить тяжёлые файлы: models/, vendor/, voice/, data/body3d.bin, public/.
