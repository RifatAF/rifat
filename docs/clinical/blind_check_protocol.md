# Протокол: слепая проверка на 10 случаях

Зачем: понять, совпадает ли приложение с независимым специалистом.

## Договориться заранее
- Углы (глубина приседа, колено внутрь, повороты, руки вверх): совпало, если ICC(2,1) > 0,75 и пределы согласия Бланда–Альтмана не шире ±5°.
- Наблюдения да/нет («колено уходит внутрь», «пятки отрываются»): совпало, если каппа Коэна > 0,6.

## Как провести
1. 10 человек, у каждого тест в приложении; одновременно видеозапись на второй телефон сбоку и спереди.
2. Второй специалист получает только видео, без выводов приложения, и размечает углы (например, Kinovea) и наблюдения да/нет.
3. Разметку специалиста и числа приложения свести в таблицу (выгрузка: Администрирование → «Выгрузить данные для анализа»).
4. Посчитать ICC, пределы согласия, каппу.

## Результат
Протокол с таблицей: какие показатели совпали, какие нет. Несовпавшие не показываем клиенту (карточка «Оставить только стабильные показатели»).
