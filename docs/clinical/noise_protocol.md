# Протокол: шум повтора на 10 знакомых

Зачем: узнать, какое изменение по каждому показателю — просто разброс теста. Меньше порога пишем «в пределах погрешности», а не «прогресс».

## Кого и когда
- 10 человек без острой боли, разный рост и комплекция.
- День 1: два теста подряд с интервалом 2–5 минут, без упражнений между ними (короткий интервал).
- День 4: третий тест в то же время суток (длинный интервал).

## Как снимать (одинаково каждый раз)
- Тот же телефон, та же точка и высота, вертикально, человек в 2,5–3 м.
- Обтягивающая одежда, свет спереди, однотонный фон.
- Во втором тесте (контрольный повтор) экран подсказывает «ближе/дальше» по первому кадру. В третьем ставить телефон по меткам на полу.

## Как провести в приложении
1. Администрирование → Режим сеанса: включить «Режим сеанса» и «Контрольный повтор».
2. Кабинет специалиста → «Сеанс» → выбрать жалобы (или «Профилактика») → отметить «Клиент согласен помочь калибровке».
3. Первый тест → «Повторить сразу» (контрольный повтор). Пара уйдет на сервер как контрольная.
4. Через 3 дня: тот же «Сеанс» и те же жалобы, без контрольного повтора. Эту пару (день 1 и день 4) приложение само не связывает: разницу 1–3 считаем по выгрузке (Администрирование → «Выгрузить данные для анализа») или по записям сеансов.

## Что получится
- Сервер раз в сутки считает по контрольным парам погрешность каждого признака (SEM и MDC95 = 1,96·√2·SEM), отдельно для интервала меньше 15 минут. Порог подставляется в сравнение автоматически, когда пар 10 и больше.
- Таблица для отчета: человек, тест, глубина приседа, колено внутрь, наклоны, повороты, руки вверх; разница 1–2 и 1–3.

Критерий: по каждому показателю записана цифра «изменение меньше X считаем шумом».
