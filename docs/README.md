# Документы запуска (не публикуются на сайте)

- `legal_texts/` — юрист: тексты, черный список, поток данных, режим запуска, чеклист, предложение по клиентскому интерфейсу, страница «Чего не умеет».
- `clinical/` — клиницист: протокол шума повтора, протокол слепой проверки.
- `product/` — продакт: стоп-лист на 14 дней, правила решений.
- `sales/` — продажи: таблица 30 специалистов, таблица отказов, сообщение и демо.
- `strategy/` — стратегия продвижения на 90 дней (с 19.10.2026) и бэклог из 40 задач. Главный ориентир для продаж и контента.

Доски задач в Trello:
- «BodyPassport: 90 дней продвижения» (https://trello.com/b/Vcm8XDxn): продажи, контент, пилоты, решения;
- «BodyPassport: запуск и продажи» (https://trello.com/b/rYxEtKmk): юрист, клиницист, продукт.
