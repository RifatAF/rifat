# ТЗ (финальная версия v4): «Быстрый тест» из 4 фото, тарифы, установка, лендинг

Для: сессия Claude Code. Автор: Рифат. Дата: 22.10.2026. Заменяет v1, v2 и v3.
Сначала изучи код и ответь, как вписать задачу и в каком порядке делать. Ничего существующего не удаляй: напоминания, упражнения, «Тест из дома», «Сеанс», тест по видео, форма обратной связи остаются и уходят в раздел «Ещё».

## 1. Цель и преимущество над PostureScreen

Специалист за несколько минут делает 4 фото клиента (по одному с каждой стороны), приложение само ставит точки, специалист быстро правит, затем показывает клиенту 3D-фигурку в его позе и отправляет PDF. Результаты сохраняются для «было → стало».

Преимущества: автоматическая разметка всех 4 фото и правка по касанию; наглядная фигурка в позе клиента; «Всё совпадает» одной кнопкой; бесплатный старт без докупок; работа в браузере без установки; отчёт «было → стало».

## 2. Границы обещаний (строго)

1. Нет диагнозов, причин боли, лечения, оценок «норма / не норма».
2. Приложение не «определяет» и не «выявляет» состояние мышц. Подсказки по зонам только как предположение для специалиста.
3. Клиенту и в PDF попадает только подтверждённое специалистом, с подписью «гипотеза специалиста».
4. Нельзя писать «точнее лаборатории», «клиническая точность». Можно: «замер по фото, с погрешностью X».
5. Порядок в отчёте: измерено → что видно → вывод специалиста → действие специалиста. Метки «ЗАМЕР» и «ГИПОТЕЗА».
6. В каждом PDF внизу: «Отчёт не является медицинским заключением и не заменяет консультацию врача».
7. Слова из чёрного списка docs/legal_texts не использовать.

## 3. Путь специалиста

**0. Регистрация.** Один шаг, вход по почте или Google, до 30 секунд, без обязательного подтверждения письмом. Долгая сессия, дальше вход автоматический. Собирать минимум данных (почта).

**1. Кабинет.** Список клиентов, поиск, большая кнопка «Быстрый тест». В «Ещё»: напоминания, упражнения, «Тест из дома», «Сеанс», тест по видео, настройки, тариф.

**2. Быстрый тест.** Выбрать клиента (достаточно имени или метки) или «Без карточки». Перед съёмкой отметка согласия клиента (раздел 6). Ровно 4 фото с силуэтом-подсказкой: спереди («Встаньте лицом ко мне у стены»), справа, сзади, слева. На каждом фото: уровень по гироскопу, контур, подсказки по расстоянию и свету, проверка кадра, «Переснять».

**3. Точки.** Приложение само ставит точки на каждом фото. Правка по касанию с лупой, сетка и отвес. Кнопка «Все точки верны».

**4. Анализ.** Кнопка «Готово». Считаются измеренные значения (смещения, углы по видам) с погрешностью (docs/clinical/noise_protocol.md). Только числа, без оценок.

**5. Фигурка.** Существующая 3D-фигурка принимает позу клиента по его точкам (это положение на типовой фигурке, а не тело клиента). На ней до 8 основных зон с тремя статусами: «слабая», «зажатая», «перерастянутая (держит напряжение)». Подсказки строит существующий набор правил проекта (карта зон Рифата и веса источников), новых связей не придумывать. Специалист по касанию меняет статус или убирает зону. Кнопки: **«Всё совпадает»** (подтвердить все) и «Изменить». До подтверждения подсказки видны только специалисту с подписью «предположение, проверьте».

**6. Кнопка «Усилить».** Визуально увеличивает отклонения на фигурке (множитель 1.5, 2 или 3). По умолчанию выключена. Всегда плашка «Показано с увеличением ×N, не реальный масштаб». Числа в отчёте остаются реальными. В PDF попадает только если специалист включил, с той же плашкой. В «было → стало» оба замера с одним множителем.

**7. Показать клиенту.** Полноэкранный режим: фигурка и подтверждённые зоны, крупный текст, без кнопок специалиста.

**8. Отчёт.** PDF и ссылка: измерено, что видно, вывод специалиста (подтверждённые зоны), рекомендации специалиста (из существующих карточек «Укрепить / Расслабить» и упражнений), метки и юридическая строка. Кнопка «Отправить».

## 4. Платформы, установка, встроенные браузеры

1. **Android Chrome:** кнопка «Установить» через системное окно установки (событие beforeinstallprompt, нужны манифест, service worker и HTTPS). Показывать после первого готового отчёта, не до теста.
2. **iPhone, Safari:** окна установки нет. После первого готового отчёта показывать подсказку с картинкой «Поделиться → На экран Домой». Chrome на iPhone установить не может, подсказывать открыть в Safari. Не показывать подсказку, если приложение уже открыто в режиме приложения (display-mode: standalone).
3. **Встроенные браузеры Instagram и Telegram:** камера может не работать (в Facebook на Android нет нужных API, в Telegram на Android поле выбора файла открывает галерею вместо камеры). Определять встроенный браузер и показывать крупную подсказку «Откройте ссылку в Chrome или Safari» с кнопкой «Копировать ссылку». До этого не пускать к камере.
4. **Хранение данных на iPhone.** Страница в Safari и установленное приложение хранят данные раздельно. Safari может очищать данные сайтов, которыми не пользовались неделю (проверить), установленные приложения нет. Решение: до первого реального клиента предложить установку, плюс экспорт и импорт данных одним файлом, плюс предупреждение «Данные хранятся на этом устройстве». Проверить сценарий «сделал замеры в Safari, потом установил».
5. **Напоминания (push) на iPhone** работают только в установленном приложении, разрешение запрашивать не при загрузке страницы, а по нажатию кнопки.
6. **Евросоюз:** проверить поведение установленных приложений на iPhone (оно менялось), не обещать функции без проверки.
7. Проверять на iPhone, минимум двух слабых Android и на компьютере.

## 5. Данные (по умолчанию самые осторожные настройки)

1. Фото, точки, выводы и имена клиентов хранятся только на устройстве специалиста. На сервер по умолчанию не отправляются.
2. Лицо на сохранённых фото и в отчёте размывается по умолчанию (настройка).
3. Резервная копия на первом этапе: ручной экспорт файла, зашифрованного ключом специалиста, и импорт. Серверная резервная копия за флагом, выключена до ответа юриста.
4. «Было → стало» работает по локально сохранённым замерам. Перенос между устройствами через экспорт и импорт.
5. Фразу «фото не уходят с телефона» использовать только после проверки сетевых запросов.
6. Данные аккаунта специалиста (почта) и платежи: по решению юриста (раздел 10).

## 6. Согласие клиента

1. Перед первым тестом экран согласия: что снимаем (4 фото и измеренные значения), зачем (показать результат и сравнить через время), где хранится (на устройстве специалиста), срок хранения, право отозвать и удалить.
2. Факт согласия сохраняется вместе с замером (дата, имя или метка).
3. Текст согласия утверждает юрист.

## 7. Тарифы и оплата

**Старт.** Первые 30 дней у каждого специалиста полный PRO, карта не нужна. Пробный период реализовать на нашей стороне (поле «дата окончания пробного периода»), не полагаясь на lava.top. Затем: оплата PRO или переход на Бесплатный тариф (без блокировки и без потери данных).

**Бесплатный тариф (работает полностью):** 4 фото, авторазметка и правка, фигурка в позе клиента, зоны, «Усилить», «Показать клиенту», PDF с небольшой подписью «Сделано в BodyPassport», до 5 активных клиентов, «было → стало» по двум последним замерам, напоминания, «Тест из дома» до 3 в месяц.

**PRO (899 ₽ в месяц):** без лимита клиентов, PDF со своим логотипом и контактами без подписи BodyPassport, история всех замеров и график динамики, «Тест из дома» без ограничений, серверная резервная копия (после юриста).

**Предложения:**
1. Вводная цена: первые 3 месяца 449 ₽, потом 899 ₽. Показывать в конце пробного периода.
2. Годовой тариф около 6 990 ₽.
3. «Цена основателя» для первых 10 специалистов: 449 ₽ навсегда, выдаётся вручную через флаг.

**Правила:**
1. Все лимиты и цены задаются настройками, без изменений кода.
2. При превышении лимита клиентов старые данные остаются доступны для просмотра и экспорта, нельзя только создавать новых клиентов сверх лимита.
3. Оплата через lava.top (подписки с автосписанием, уведомления о платежах). Статус PRO выставлять по уведомлению о платеже и по окончании периода. Для вводной цены и цены основателя использовать отдельные продукты или промокоды. Перед реализацией уточнить в поддержке lava.top возможности пробного периода и вводной цены. Комиссия lava.top 8%, учитывать в расчётах.
4. Не показывать цену в основном пути, пока идёт пробный период. Тариф в «Ещё → Тариф».

## 8. Лендинг и аналитика

1. На bodypassport.app для невошедших первым экраном лендинг, для вошедших сразу кабинет.
2. Содержание сверху вниз: заголовок «Покажите клиенту его прогресс, а не просто рассказывайте о нём»; ролик на 60–90 секунд; три шага (4 фото, правка точек, отчёт с фигуркой); строка «Не диагноз и не медицинское заключение. Решения принимает специалист»; про данные (только проверенное); кнопка «Попробовать бесплатно 30 дней».
3. Все ссылки из соцсетей с метками (utm_source, utm_campaign).
4. События для воронки (без персональных данных клиентов, анонимные идентификаторы): открытие страницы, регистрация, первый тест начат, первый отчёт, второй тест в течение 14 дней, установка, подписка, оплата.
5. Лендинг делать после этапа 1 приложения.

## 9. Обратная связь

Обновить форму: после теста и по кнопке «Оставить оценку». Вопросы:
1. Кому из клиентов вы покажете этот отчёт? Один пример (текст).
2. Когда вы бы использовали: до занятия, после, раз в месяц, нигде (выбор).
3. Что мешает использовать (выбор и «другое»).
4. Что бы вы изменили в отчёте (текст).
5. При какой цене в месяц это показалось бы вам дорогим? (число)
6. При какой цене слишком дёшево, чтобы доверять? (число)
7. Что из платной версии вам было бы нужно? (выбор: больше клиентов, свой логотип, история и график, тест из дома, резервная копия)
8. Были ли случаи, когда вы чувствовали, что решает приложение, а не вы? Когда? (текст)
Сохранять с анонимным идентификатором и датой, нужна выгрузка. Кнопка «Поделиться» ссылкой на сервис, нажатия считать.

## 10. Юридические вопросы (по состоянию на 22.10.2026, требуют подтверждения юристом)

1. **Медицинское изделие.** Программа считается медизделием, если предназначена для диагностики или поддержки врачебных решений. Риск: подсказки по мышцам. Поэтому подсказки только для специалиста, клиенту только подтверждённое. Показ вероятностей клиенту напрямую не делать до письменного ответа юриста.
2. **Специальные категории данных** (здоровье): отдельное явное согласие с целями. Экран согласия в разделе 6.
3. **Локализация:** первичный сбор данных граждан РФ в базах за рубежом ограничен (поправки 1 июля 2025 года, высокие штрафы). Поэтому данные клиентов на сервер не отправляются.
4. **Трансграничная передача:** разрешена при уведомлении Роскомнадзора, источники расходятся по вопросу согласия.
5. **Аккаунты специалистов** (почта) и **роль оператора данных** при работе из Аргентины: решение юриста.

## 11. Этапы

**Этап 1:** регистрация, кабинет, клиенты, согласие, 4 фото, авторазметка и правка, расчёт, PDF (измерено + вывод специалиста), локальное хранение, экспорт и импорт, определение встроенного браузера, установка (Android и iPhone), перенос старого в «Ещё», событие аналитики.
**Этап 2:** фигурка в позе клиента, зоны (режим «для специалиста»), «Всё совпадает», «Усилить», «Показать клиенту», рекомендации в PDF, лендинг, обновлённая форма обратной связи.
**Этап 3:** «было → стало» и график, тарифы и оплата через lava.top, пробный период, вводная цена, цена основателя, размытие лица, серверная резервная копия за флагом (после юриста).

## 12. Приёмка

1. Новый специалист регистрируется, делает 4 фото и получает PDF за 5 минут и не более 15 нажатий.
2. Правка точки с лупой пересчитывает результат сразу.
3. Клиент видит только подтверждённые специалистом зоны с подписью «гипотеза специалиста». Слов «определило», «выявило» и слов из чёрного списка нигде нет.
4. При настройках по умолчанию фото и персональные данные клиентов не уходят на сервер (проверить по сетевым запросам).
5. «Усилить» всегда с плашкой, по умолчанию выключено, числа не искажаются.
6. В каждом PDF строка «не является медицинским заключением».
7. Из встроенного браузера Instagram и Telegram показывается подсказка «Откройте в Chrome или Safari», камера не вызывается.
8. Установка работает на Android Chrome и в Safari на iPhone, данные сохраняются после установки (или предупреждение и экспорт).
9. Пробный период, лимиты и цены меняются настройками. После окончания пробного периода данные сохранены.
10. Статус PRO выставляется по уведомлению lava.top.
11. События воронки пишутся без персональных данных клиентов.
12. Старые функции доступны из «Ещё» и работают как раньше.
13. Работает на iPhone и минимум двух слабых Android.
