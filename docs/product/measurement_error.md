# Погрешность замеров «Быстрого теста»

С 24.10.2026 в интерфейсе и отчете погрешность («± 1,5°») не показывается рядом с числами: она сбивала глаз.
Вместо этого приложение показывает только значения больше погрешности, а значения в ее пределах помечает словами
«в пределах погрешности» (в списке «Все замеры») или не подписывает вовсе (на фото, в отчете).

Погрешность по-прежнему используется в расчетах, значения заданы в `js/quick-metrics.js` (`ERR`):

| Показатель | Вид | Погрешность |
|---|---|---|
| Наклон головы | спереди, сзади | 2° |
| Линия плеч | спереди, сзади | 1,5° |
| Линия таза | спереди, сзади | 1,5° |
| Смещение корпуса | спереди | 1,5° |
| Голова относительно плеча | сбоку | 4° |
| Плечо относительно таза | сбоку | 1,5 см (без роста: 0,9% роста) |
| Таз относительно лодыжки | сбоку | 1,5 см (без роста: 0,9% роста) |
| Колено относительно линии бедро–лодыжка | сбоку | 3° |

Откуда числа: стартовая оценка по точности точки модели позы (1–2 % кадра) и ручной правке. Уточняются по
`docs/clinical/noise_protocol.md`, когда будет 10 пар повторных замеров; меняются только в `ERR`, формулы не трогаются.

Где погрешность влияет на интерфейс:
- «Что видно», подписи на фото и PDF: только показатели с |значение| > погрешности;
- «Было → стало»: «без изменений», если разница двух замеров не больше погрешности;
- зоны (предположение) строятся по тем же правилам, что и раньше.
