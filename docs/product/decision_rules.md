# Правила решений (фиксируются до старта продаж)

1. 30 контактов дали меньше 5 оплат → меняем оффер или сегмент, продукт не трогаем.
2. Ретест у клиентов меньше 15% за 14 дней → чиним контур ретеста (напоминания, ссылка, дата), новые функции не делаем.
3. Отказ «нет функции» меньше 3 раз → функцию не делаем.
4. Каждое решение записываем: дата, цифры, что решили.

Цифры берем из Администрирование → Статистика и отзывы и из таблицы отказов.
