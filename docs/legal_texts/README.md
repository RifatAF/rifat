# legal_texts

Материалы для юриста по карточкам доски Trello «BodyPassport: запуск и продажи».

- `all_strings.tsv` — все русские строки интерфейса, сайта и бота с файлом и строкой кода.
- `danger_places.md` — строки с диагностическими словами, мышцами, процентами, «измерено» и обещанием про видео. Состояния HYPER в кабинете специалиста 19.10 переименованы в «Перерастяжение» (pro.js:224, pro.js:819).
- `blacklist.md` — черный список слов и таблица замен (черновик на утверждение).
- `data_flow.md` — фактический поток данных по коду.
- `screens/` — скриншоты клиентского интерфейса на демо-результате.

Не собрано автоматически: скриншоты кабинета специалиста (нужен вход), PDF специалиста, переписка с ботом в Telegram.

Замечено на скриншотах (19.10): на главном экране результата клиент видит «Отсюда может быть: колено ноет на лестнице или после бега» (причина боли), карту мышц с состояниями «зажата», «перегружена», «недорабатывает» и список «Все зоны» с мышцами (`screens/04-overview.png`).
