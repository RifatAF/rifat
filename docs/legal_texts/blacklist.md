# Черный список слов и таблица замен (черновик для юриста)

Статус: черновик 19.10.2026, ждет утверждения юристом. Где применяется: клиентский интерфейс, клиентский PDF и ссылка, лендинг, публичный маркетинг, сообщения бота клиенту. В закрытом кабинете специалиста профессиональные термины допустимы, если юрист не решит иначе.

| Запрещено | Почему | Чем заменить |
|---|---|---|
| диагноз, диагностика, «выявляет» | медицинская деятельность | «оценка движения», «наблюдение», «показывает, как вы двигаетесь» |
| лечение, лечит, лечебный, «исправляет» | медицинское заявление | «упражнения», «занятия», «что можно потренировать» |
| причина боли, «боль из-за…» | причинно-следственное медицинское заявление | «что видно в движении»; о боли только «если болит, покажитесь врачу» |
| гипертонус, тонус | термин состояния мышцы, по камере не измеряется | наблюдаемое: «плечо поднимается к уху», «амплитуда меньше» |
| укорочение, укорочена, зажатость | то же | «амплитуда меньше», «наклон вперед не до пола» |
| слабость мышцы, ослаблена, «не работает» | то же | «колено уходит внутрь», «таз проседает, стоя на одной ноге» |
| перегруз, перегрузка, перерастяжение | то же | «стоя на правой ноге, таз проседает», «в приседе спина наклоняется вперед» |
| проценты мышц («ягодичная 40%») | выглядит как измерение, хотя это вывод правил | убрать; показывать углы в градусах и «в пределах погрешности» |
| «ИИ анализирует», «искусственный интеллект» | завышенное обещание точности | «приложение считает углы по камере» |
| «измерено» о выводах правил | вывод выдается за замер | «измерено» только для углов и повторов; для выводов «предположение» |
| «видео не покидает телефон» | верно только про видео | «Видео не записывается и не уходит с телефона. Результаты теста хранятся в облаке, чтобы не потеряться» |
| «точность 95%», «клинически доказано» | нет подтверждения | «у теста есть погрешность, сравнивать надежнее через неделю» |

Разрешенный язык (наблюдаемое): «пятки отрываются от пола», «колено уходит внутрь», «амплитуда меньше», «присед стал глубже», «на третьем визите пятки не отрывались», «в пределах погрешности».

Где уже соблюдается: экраны режима «Сеанс» (проверка в tests/session.test.mjs). Где нарушается: см. `danger_places.md`.
