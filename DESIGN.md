# BodyPassport: файлы для работы над UX/UI

Живая версия: https://bodypassport.vercel.app · тарифы /pricing · политика /privacy

## Как устроено
Одностраничное веб-приложение без сборки: обычные HTML, CSS и JS-модули. Экраны рисуются строками HTML в функциях JS (`go(...)`), стили и цвета в `index.html`.

| Файл | Что внутри |
|---|---|
| `index.html` | Стили, цветовые токены (`:root`), шрифт Onest, точка входа |
| `js/app.js` | Режим клиента: знакомство, подготовка, тест, карта тела, итог «Укрепить / Растянуть / Расслабить» (`verdictCard`), упражнения, настройки |
| `js/pro.js` | Кабинет специалиста: клиенты, новая оценка, результат (вкладки Измерено / Гипотеза / Назначение), отчет-картинка, было → стало |
| `js/auth.js` | Экран входа (Google, Telegram), согласие, экран противопоказаний |
| `js/plans.js` | Тарифы, ограничения, специализации и порядок шаблонов |
| `js/core.js` | Камера и распознавание позы, тепловая карта тела, 3D, голос |
| `js/analysis.js` | Расчет: признаки, правила, цепи, тон мышц |
| `data/*.json` | Мышцы (названия, тесты руками), правила, цепи, упражнения |
| `pricing.html`, `privacy.html` | Отдельные страницы |
| `api/*.js` | Сервер на Vercel: вход и пересылка результатов. Для дизайна не нужен |

## Цветовые токены
Фон `#F4F0E8`, основной `#1E2533`, акцент `#C6E84B`, коралловый `#E8765A`, текст `#1C1B19`.
Состояния мышц: перегрузка `#E5484D`, укорочение `#EE7B30`, слабость `#3B7BE8`, норма `#2E9E6A`.

## Принципы, о которых договорились
1. Сначала картинка, потом не больше 3 строк итога, детали по нажатию.
2. Итог для всех специалистов одним языком: Укрепить / Растянуть / Расслабить + одна измеренная деталь.
3. Один экран, одно решение. Не больше 10 слов на пункт.
4. Массажист: «Осанка до и после сеанса» за минуту, без приседаний.
5. Цель по скорости: результат за 3 минуты, до главного действия не больше 3 нажатий, на экране результата меньше 60 слов.

## Ключевые экраны для редизайна
Знакомство → вход → противопоказания → подготовка → тест → карта и итог (клиент).
Кабинет → выбор специализации → новая оценка → результат (3 вкладки) → отчет (специалист).

Папки `models/`, `voice/` и файл `data/body3d.bin` (модель позы, озвучка, 3D-модель тела) большие и для дизайна не нужны, в архив не включены. Для запуска локально их можно взять с живого сайта.
